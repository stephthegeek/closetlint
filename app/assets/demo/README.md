# Fictional demo wardrobe

Twelve original AI-generated product photos of invented, unbranded pieces. These are demonstration assets, not retailer photographs or listings. Generated on 2026-10-19 with OpenAI’s built-in image generation tool.

Full prompts, file names, and dimensions are recorded in `provenance.json`. The photos are capped at a 1600px longest edge, without upscaling. Full generated PNG sources are retained in the development workspace; these optimized JPEGs are bundled so the demo needs no image-generation account or extra Python packages.
