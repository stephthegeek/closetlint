SPDX-License-Identifier: GPL-3.0-or-later

These PNG originals are the available editable raster forms of Linty:

- linty-logo-original.png — full mascot/logo artwork.
- linty-side-peek-sock.png — side-peeking mascot holding a sock.
- linty-favicon-face-1024.png — large face artwork.

The current editable favicon is ../linty-smile.svg. Smaller exports and
inline app images are derived assets. No layered project files exist for
these originals. These files contain generative image-tool provenance;
see the root AI-USE-AND-SECURITY.md.
